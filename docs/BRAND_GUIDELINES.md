# Frontline Advantage: Brand Guidelines

## Brand Identity

### Vision
Empower frontline workers and teams to grow, master skills, and advance their careers through AI-driven capability development.

### Brand Positioning
**The Duolingo for Workforce Skills**

We replace traditional learning with AI-first capability growth that's:
- **Engaging** — Daily learning in 5 minutes
- **Intelligent** — Personalized to your role and gaps
- **Practical** — Skills you use immediately at work
- **Measurable** — Real capability growth in 60 days

### Brand Personality

| Dimension | Personality |
|-----------|-------------|
| **Modern** | Contemporary, forward-thinking, current |
| **Premium** | High quality, enterprise-grade, professional |
| **Human** | Approachable, supportive, empathetic |
| **Intelligent** | Smart, data-driven, insightful |
| **Growth-Oriented** | Ambitious, aspirational, enabling |

### Tone of Voice

**What we sound like:**
- Direct and clear (no jargon)
- Encouraging and supportive
- Confident but not arrogant
- Helpful and practical
- Action-oriented

**What we avoid:**
- Corporate speak
- Overly casual
- Vague or unclear language
- Patronizing tone
- Buzzwords without substance

**Examples:**
- ✅ "Learn one skill this week" (clear, actionable)
- ❌ "Synergize your learning ecosystem" (jargon)
- ✅ "Your manager believes in you" (human, supportive)
- ❌ "Stakeholder alignment required" (corporate)

## Visual Identity

### Logo

**Logo Mark:** F + A combination forming ascending arrow
- **F:** Three descending horizontal bars (navy)
- **A:** Triangle with internal trapezoid (blue to teal gradient)
- **Arrow:** Upward trajectory through triangle (represents growth)

**Logo Variants:**
1. Full logo (mark + wordmark)
2. Mark only (icon)
3. Horizontal lockup
4. Vertical lockup
5. Monochrome (black)
6. Monochrome (white)

**Logo Usage:**
- Minimum size: 40px (digital), 0.5 inch (print)
- Clear space: Equal to height of mark
- Never alter proportions or rotate
- Always maintain contrast with background

| Scale | Value | Usage |

| **2xs** | 4px | Tight spacing, micro-interactions |

| **sm** | 12px | Compact spacing |
| **md** | 16px | Standard spacing |
| **lg** | 24px | Comfortable spacing |
| **xl** | 32px | Generous spacing |
| **2xl** | 48px | Large section spacing |
| **3xl** | 64px | Hero spacing |

### Practical Spacing Examples

- **Button padding:** md (16px) horizontal × sm (12px) vertical
- **Card padding:** lg (24px)
- **Section margin:** 2xl (48px)
- **Component gap:** md (16px)
- **List item spacing:** md (16px)

## Photography & Imagery

### Photography Style

- **Authenticity:** Real people, real work environments
- **Diversity:** Represent all user populations and backgrounds
- **Activity:** Show people learning, collaborating, growing
- **Tone:** Professional, aspirational, but accessible
- **Contrast:** Mix of wide shots and close-ups

### Illustration Style

- **Approach:** Flat, geometric, modern
- **Color palette:** Use brand colors (Emerald, Navy, Electric Blue)
- **Complexity:** Simple, not detailed
- **Consistency:** Same style across all illustrations
- **Purpose:** Support narratives, not replace text

### Icons

- **Style:** Outlined, 24x24px base size
- **Stroke width:** 2px
- **Corner radius:** 2px
- **Consistency:** All icons follow same construction grid
- **Color:** Match text color or semantic color

## Accessibility

### Color Contrast

**WCAG AA Compliant (4.5:1 minimum)**

- Navy text (#0A1F44) on Soft White (#F8F9FB): 15.8:1 ✓
- Emerald text (#00C48C) on White: 4.8:1 ✓
- Electric Blue text (#2F80ED) on White: 6.1:1 ✓
- White text on Emerald (#00C48C): 4.8:1 ✓
- White text on Navy (#0A1F44): 15.8:1 ✓

### Typography
- Minimum font size: 12px (help text), 14px (small text), 16px (body)
- Line height minimum: 1.4 for accessibility
- Letter spacing preserved for readability
- Focus states clearly visible (2px borders, high contrast)

### Interactive Elements
- All buttons keyboard accessible
- Focus indicators always visible
- Color not sole indicator (icons, text labels)
- Touch targets minimum 44x44px

## Brand Dos and Don'ts

### ✅ Do
- Use brand colors purposefully
- Maintain consistent typography
- Keep designs clean and uncluttered
- Use high-quality imagery
- Preserve logo clear space
- Test for accessibility
- Update design system as brand evolves

### ❌ Don't
- Alter logo proportions or rotate
- Use unofficial color variations
- Mix font families without purpose
- Use outdated imagery
- Ignore spacing standards
- Forget about dark mode
- Compromise on accessibility
